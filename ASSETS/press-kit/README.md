# Somatic Canticles — Press Kit / Brand Assets

This folder contains the core visual brand assets for the trilogy.

## Contents

- `press--brand-mark.png` — Primary logo / wordmark
- `press--icon-set.png` — Icon library
- `press--palette.png` — Color palette
- `press--pattern-library.png` — Background patterns and textures
- `press--photo-style.png` — Reference for photography / image treatment
- `press--tone-board.png` — Overall mood and feeling references
- `press--type-specimen.png` — Typography system
- `press--visual-language.png` — Overall visual direction and composition guidelines

## Usage

These assets are intended for:
- Press materials
- Partner / retailer assets
- Internal brand consistency
- Marketing collateral that needs to feel "on-brand"

For the actual book covers and marketing imagery, see the `covers/`, `merch/`, and `marketing/` folders.
