# CR-10 package index

This folder closes the cosmology-refinement campaign as a review package.

- `delivery-manifest.json` records package identity, artifact hashes, scope limits, and canon/app boundaries.
- `export-parity.json` records why compiled export regeneration is deferred until accepted source promotion.
- `release-checklist.md` names what is review-ready and what remains unperformed.
- `reader-feedback.md` defines measured re-entry without moral scoring.
- `final-verification.json` is written after tests and diff checks pass.
